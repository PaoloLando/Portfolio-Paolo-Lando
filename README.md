# Portfolio Web de Paolo Landó

**Autor:** Paolo Landó
**Actividad:** Actividad integradora Unidad 3 - Desarrollo de un Portfolio Web

## Descripción

Portfolio web personal donde presento quién soy, mi formación, las tecnologías que conozco y los proyectos en los que trabajé. Soy estudiante de programación y mi área de interés es el desarrollo backend.

El sitio tiene cuatro secciones: **Inicio**, **Sobre mí**, **Proyectos** y **Contacto**. Está hecho desde cero, es responsive y usa los colores azul y amarillo.

## Tecnologías utilizadas

- **HTML5:** estructura del sitio con etiquetas semánticas (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`), listas, enlaces, imágenes y formulario.
- **CSS3:** hoja de estilos externa con variables, Flexbox, CSS Grid, `display`, `position`, unidades relativas y media queries.
- **JavaScript:** variables, constantes, funciones, estructuras de control, eventos y manipulación del DOM.
- **Git y GitHub:** control de versiones y alojamiento del proyecto.

## Principales funcionalidades

- **Modo oscuro y claro:** un botón en el encabezado cambia el tema y recuerda la elección.
- **Menú responsive:** en celulares el menú se oculta y se despliega con un botón.
- **Proyectos dinámicos:** las tarjetas se crean con JavaScript a partir de un arreglo de objetos.
- **Buscador de proyectos:** filtra las tarjetas por nombre o tecnología mientras se escribe.
- **Formulario de contacto validado:** controla nombre, email y mensaje, muestra errores en cada campo, cuenta los caracteres del mensaje y muestra una confirmación al enviar. El formulario no envía los datos a ningún servidor, solo valida la información.
